 News App
A dynamic and responsive News Application built with React.js and Bootstrap. The app fetches and displays the latest news articles in various categories, offering a clean UI and smooth user experience. It demonstrates the use of React components, props, state management, API integration, and conditional rendering.

🚀 Features
Fetches real-time news from a public news API

Category-wise news filtering (e.g., Business, Sports, Technology, etc.)

Pagination support for browsing more articles

Responsive UI using Bootstrap

Loading spinner for improved UX

Clean and modular component structure

Error handling for API responses

🛠️ Tech Stack
Frontend: React.js

Styling: Bootstrap 5, Custom CSS

Language: JavaScript (ES6), JSX

API: News API
